GitHub stats, rendered as sci-fi cards.

Contributor Codex turns a username, an org, or a repo into a hand-drawn SVG card — no build step, no tracking pixel, just a URL you can drop into a README.

Four kinds of card

Each one is a live SVG, generated on request from real GitHub data — not a cached screenshot.

Contributor

A profile card built from a single username — stats, top language, four themes.

/api/card?username=

Team / Leaderboard

Point it at an org and every public member gets ranked by a transparent, self-referential XP formula.

/api/leaderboard?org=&limit=

Repository

Stars, forks, license, topics, contributors, and the latest release for a single repo.

/api/repo?owner=&repo=

Achievements

Tiered badges for stars, repos, followers, years active, languages, forks, and licensed work.

/api/trophies?username=&trophies=
